# MemoirRush

A Windows Forms productivity app with daily, weekly, monthly and sticky task lists, plus user sign-up and login. Data is saved locally as JSON.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![WinForms](https://img.shields.io/badge/Windows_Forms-0C54C2?style=flat-square)

## Features

- **Sign up / Log in** screens
- **Four task lists:** daily, weekly, monthly and sticky (persistent) notes
- Check off everything for the day and it clears the list with a little motivation
- Lists are serialised to JSON so they survive restarts

## Build

Open `MemoirRush.sln` in Visual Studio and run.
